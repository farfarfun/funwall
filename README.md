
# funwall

funwall 是科学上网资源索引，汇总代理服务端安装脚本、跨平台客户端与机场信息。
Python 包仅提供版本信息，方便从 PyPI 跟踪索引版本。

## 安装

```bash
pip install funwall
```

## 最小示例

```python
import funwall

print(funwall.__version__)
```
